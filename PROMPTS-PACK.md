**Pacote Groq Starter: 8 Prompts de Alta Velocidade**

Este pacote foi otimizado para os modelos rápidos do Groq (como qwen/qwen3.6-27b ou openai/gpt-oss-20b), focando em latência mínima e resultados imediatos.

**1. Copy de Vendas Direta**
*Prompt:* "Escreva um e-mail de vendas de 150 palavras para [Produto], focando na dor [Dor Principal] e na solução [Benefício Chave]. Tom: urgente e profissional."
*Quando usar:* Campanhas de e-mail marketing rápidas.

**2. Refatoração de Código Python**
*Prompt:* "Otimize este código Python para performance e legibilidade. Explique as mudanças: [Cole o Código Aqui]."
*Quando usar:* Revisão rápida de scripts ou limpeza de código legado.

**3. Estrutura de App Chatbot**
*Prompt:* "Crie um esqueleto HTML/JS básico para um chatbot que usa a API do Groq. Inclua apenas o frontend e a função de fetch para a API."
*Quando usar:* Prototipagem inicial de interfaces de chat.

**4. Demo LPU (Low-Code UI)**
*Prompt:* "Gere um componente React funcional para um dashboard simples mostrando 3 métricas. Use Tailwind CSS para estilização. Sem lógica complexa, apenas UI."
*Quando usar:* Criar demos visuais rápidas para stakeholders.

**5. Resumo Técnico**
*Prompt:* "Resuma este artigo técnico em 3 bullet points focados em impacto prático para desenvolvedores: [Cole o Texto Aqui]."
*Quando usar:* Leitura rápida de documentação ou blogs técnicos.

**6. Geração de Testes Unitários**
*Prompt:* "Escreva 3 testes unitários em Jest para esta função JavaScript: [Cole a Função Aqui]. Cubra casos de sucesso e erro."
*Quando usar:* Garantir qualidade de código sem escrever testes do zero.

**7. Prompt de Engenharia Reversa**
*Prompt:* "Analise este erro de console: [Cole o Erro]. Sugira 3 causas prováveis e como corrigir cada uma."
*Quando usar:* Debugging rápido de erros comuns.

**8. Ideação de Features**
*Prompt:* "Liste 5 ideias de features simples para um app de [Nicho] que podem ser implementadas em menos de 2 dias usando Groq API."
*Quando usar:* Brainstorming para MVPs ou side projects.
